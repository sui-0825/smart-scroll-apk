# Smart Scroll - Android APK 配布ページ

Smart Scroll のインストール用ページです。開発ソースは別の非公開リポジトリで管理しています。

## 現在の状況

**準備中（2026-10-16）** — Ver.0.1 の Android 試作版はビルド成功しましたが、シークバー認識やジェスチャーの実機動作は未検証です。そのため、まだここに一般公開用APKを置いていません。

先にテスト用 Android 端末1台で動作を確認してから、配布版APKと共通QRコードのリンクを公開します。

## 今後のインストール方法（予定）

1. 共通QRコードを読み込んで本ページの Releases を開く
2. 配布済みの APK をダウンロード
3. AndroidでAPKの内容を確認してインストール
4. ユーザー補助のアクセスを利用者が明示的に許可
5. 対象アプリと実行条件を設定して開始・停止をテスト

**注意:** Androidのユーザー補助権限は強力な権限です。信頼できるAPKであることを確認し、利用対象アプリの規約と端末の安全設定に従ってください。インストールは自動では行われません。配布版でも利用者が操作・許可する必要があります。

開発コード・D&Dアプリ・猫監視アプリとは連携していません。
